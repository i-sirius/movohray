## RU Labs — frequency ordering

The expanded RU Labs target pool uses frequency ordering from **hingston/russian**, which is derived from the University of Leeds Corpus.

- Project: hingston/russian
- Source repository: https://github.com/hingston/russian
- Upstream data: University of Leeds Corpus
- License stated by the project: Creative Commons Attribution (CC BY)

Only entries that also occur in the Russian noun source and pass Movohray's length/target filters are used for the target pool.

## EN Labs — FrequencyWords

The expanded EN Labs target pool is frequency-ranked using **hermitdave/FrequencyWords**, with candidates restricted to words already present in Movohray's English allowed-guess vocabulary and filtered for unsuitable test targets.

- Project: hermitdave/FrequencyWords
- Source repository: https://github.com/hermitdave/FrequencyWords
- Upstream corpus for the 2018 lists: OpenSubtitles2018
- Content license stated by the project: CC BY-SA 4.0
- Repository code license: MIT

Only 5–7 letter entries that pass Movohray's target filters are added to the target pool.
