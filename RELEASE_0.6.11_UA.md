# Мовограй 0.6.11 — різні відповіді замість повторних закінчень

31 жовтня 2026. https://i-sirius.github.io/movohray/

У доборі основних відповідей додано перевірку морфологічних сімей довгих слів.
Варіанти закінчень, відмінків, чисел, дієслівних та порівняльних форм не повинні
займати декілька обов’язкових відповідей одного кола. Перевірка поєднує аналіз
включених Hunspell-словників і редакторські групи для форм, які словник зберігає
окремими записами (хутчіш/хутчіше, буде/будем/будемо, хоче/хочеш тощо).

Окремі самостійні словникові слова з різними значеннями зберігаються:
зокрема робот/робота та банк/банка. Короткі збіги кореня самі по собі не є
підставою вилучати слово. Це морфологічний та редакторський фільтр, а не повний
автоматичний аналіз усіх значень омонімів.

У збережених колах зайві форми переміщено в бонуси: гра продовжує приймати їх.
Коли після очищення лишається менше трьох незалежних основних відповідей,
коло вилучається з добору. Коло ХУТЧІШЕ / ХУТЧІШ / ХІТ вилучено саме так.

| Мова | Кіл зі зміною відповідей | Вилучених кіл | Залишилося кіл |
| --- | ---: | ---: | ---: |
| uk | 36 | 3 | 827 |
| ru | 4 | 0 | 825 |
| en | 117 | 2 | 796 |

Знайдені слова при перебудові старої сесії зберігаються: основне слово, що
стало бонусним, переноситься до знайдених бонусів без нового нарахування.
Сумісні підказані літери переносяться на нові позиції відповідного слова.
Баланс та досягнення збережено. Якщо поточне коло вилучене, гра починає інше;
вже витрачені підказки вилученого кола не відшкодовуються автоматично.
Історія досягнень зберігається, лічильник проходження враховує чинні кола.

Перевірки:

- 10770937 фізичних комбінацій звірено зі включеним словником, пропущених
  допустимих форм у збережених колах немає.
- 7344 генерації очищених кросвордів: 35214 основних розміщень,
  жодного пропущеного слова, роз’єднаної сітки чи конфлікту літер.
- Регресійна перевірка спільних лем і редакторських сімей у всіх сітках.
- Браузерні перевірки трьома мовами, балів ×1/×2/×3, бонусів, тем,
  мобільних розмірів, офлайн, міграції справжньої старої сітки та вилученого кола.
- Перевірка оновлення PWA й збереження даних інших режимів.

Команди:

```text
python -X utf8 tests/slovokolo-boards-browser.py
python -X utf8 tests/slovokolo-browser.py
python -X utf8 tests/daily-word-browser.py
```

Фільтр обов’язково запускається наприкінці tools/build-word-circle.py;
його можна окремо запустити через tools/curate-word-circle.py зі spylls==0.1.7.
Згенерований main-word-families.json потрібний для незалежної перевірки добору,
а не для завантаження гри. Початкова робоча копія не змінена.
